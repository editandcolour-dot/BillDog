# snap&track Municipality URL Index
Source: https://www.snapandtrack.co.za/electricity-tariffs
Data: NERSA-validated electricity increase percentages + block rates for some municipalities
Coverage: ~172 licensed electricity distributors across 9 provinces
Tariff year shown: 2025/26 (July 2025 - June 2026)

## How to fetch detailed rates for any municipality:
URL pattern: https://www.snapandtrack.co.za/electricity-tariffs/{province-slug}/{municipality-slug}

Example: https://www.snapandtrack.co.za/electricity-tariffs/western-cape/stellenbosch
